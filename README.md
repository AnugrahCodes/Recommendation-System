# 🛡️ Fraud Detection in Insurance Claims using Machine Learning

This project is designed to identify fraudulent insurance claims using supervised machine learning techniques. It aims to support insurance companies in automating fraud detection and improving operational efficiency.

## 📌 Key Highlights

- Preprocessed real-world-style insurance claim data
- Trained multiple ML models (Random Forest, XGBoost, Logistic Regression)
- Evaluated models using Accuracy, Precision, Recall, F1-score, ROC-AUC
- Feature importance and model interpretability
- Streamlit-based interface for demo use

---

## 🧠 Tech Stack

- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn, Streamlit (optional)
- **Model Persistence:** Joblib
- **Notebook Interface:** Jupyter
